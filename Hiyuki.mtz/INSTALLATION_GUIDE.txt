🔧 INSTALLATION STEPS:
──────────────────────

1. CONVERT TO MTZ:
   ✓ Compress Hiyuki folder with 7z or WinRAR
   ✓ Change extension to .mtz
   ✓ File name: Hiyuki.mtz

2. TRANSFER TO PHONE:
   ✓ Connect phone via USB
   ✓ Copy Hiyuki.mtz to: /sdcard/Themes/
   
   OR
   
   ✓ Use file manager on phone
   ✓ Navigate to /sdcard/
   ✓ Create "Themes" folder if not exists
   ✓ Paste Hiyuki.mtz

3. APPLY THEME:
   ✓ Open "Chủ đề" (Themes) app
   ✓ Go to "Cục bộ" (Local) section
   ✓ Find "Hiyuki Theme"
   ✓ Tap "Áp dụng" (Apply)
   ✓ Confirm and wait for installation

4. REBOOT (if needed):
   ✓ Long press power button
   ✓ Select "Restart"
   ✓ Wait for system to reboot
   ✓ Theme will be active

❓ TROUBLESHOOTING:
─────────────────

❌ Theme not showing in app:
   ✓ Clear Themes app cache
   ✓ Reboot device
   ✓ Check file location: /sdcard/Themes/
   ✓ Try refreshing the app

❌ Theme won't apply:
   ✓ Ensure file is .mtz (not .zip)
   ✓ Check filename: Hiyuki.mtz
   ✓ Verify all required files exist
   ✓ Try different theme first, then apply Hiyuki

❌ Missing elements:
   ✓ Check if all PNG files are included
   ✓ Verify XML syntax is correct
   ✓ Reinstall theme
   ✓ Clear app data and reboot

❌ Animation not working:
   ✓ Enable animations in Settings > Display
   ✓ Check animation frame files
   ✓ Reboot device
