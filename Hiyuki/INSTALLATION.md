# 🚀 INSTALLATION GUIDE - HƯỚNG DẪN CÀI ĐẶT

## English Version

### Step 1: Download Theme
1. Go to: https://github.com/thepenguin2703-hash/phrolova-theme-android
2. Click **Code** → **Download ZIP**
3. Wait for download to complete
4. Extract the ZIP file
5. Find the **Hiyuki** folder

### Step 2: Transfer to Phone
1. Connect phone to computer (optional) OR use phone file manager
2. Open **File Manager** app
3. Navigate to **Internal Storage**
4. Find or create **Themes** folder
5. Copy entire **Hiyuki** folder into **Themes**

### Step 3: Apply Theme
1. Open **Themes** app (or Settings → Personalization → Themes)
2. **Pull down** to refresh the list
3. Find **"Hiyuki"** in the list
4. **Tap** on Hiyuki
5. **Tap "Apply"** button
6. Wait 3-5 seconds
7. Theme is now applied! ✓

### Step 4: Verify
Check if these are now **RED (#C41E3A):**
- Status bar at top
- Control Center icons
- Settings header
- Toggle switches (when ON)
- Accent elements

## Phiên Bản Tiếng Việt

### Bước 1: Tải Theme
1. Vào: https://github.com/thepenguin2703-hash/phrolova-theme-android
2. Click **Code** → **Download ZIP**
3. Chờ download hoàn thành
4. Giải nén file ZIP
5. Tìm folder **Hiyuki**

### Bước 2: Chuyển vào Điện Thoại
1. Kết nối điện thoại (nếu cần) HOẶC dùng File Manager trên điện thoại
2. Mở ứng dụng **File Manager** (Trình quản lý tệp)
3. Vào **Internal Storage** (Bộ nhớ nội bộ)
4. Tìm hoặc **tạo folder** `Themes`
5. **Copy toàn bộ folder** `Hiyuki` vào `Themes`

### Bước 3: Áp Dụng Theme
1. Mở ứng dụng **Themes** (hoặc Settings → Personalization → Themes)
2. **Kéo xuống** để refresh danh sách
3. Tìm **"Hiyuki"** trong danh sách
4. **Nhấn vào** Hiyuki
5. Nhấn nút **"Apply"** (Áp dụng)
6. Chờ 3-5 giây
7. Theme đã được áp dụng! ✓

### Bước 4: Kiểm Tra
Kiểm tra xem những phần này có **MÀU ĐỎ (#C41E3A)** không:
- Thanh trạng thái phía trên
- Icon Control Center
- Header Settings
- Toggle switches (khi bật)
- Các phần accent

## 📁 File Structure

```
Internal Storage/
└── Themes/
    └── Hiyuki/                    ← Folder name (must be exact)
        ├── theme.xml              ← Main file
        ├── theme.json             ← Config
        ├── colors.xml             ← Colors
        └── README.md              ← Documentation
```

**IMPORTANT:** Folder must be named **`Hiyuki`** (case-sensitive)

## ⚠️ If Theme Doesn't Appear

### Check 1: Folder Name
- Must be: **`Hiyuki`** ✓
- NOT: `hiyuki` (lowercase)
- NOT: `Hiyuki Theme`
- NOT: `hiyuki-hyperos`

### Check 2: Folder Location
- Must be: `Internal Storage/Themes/Hiyuki/` ✓
- Path shown in File Manager: `/storage/emulated/0/Themes/Hiyuki/`

### Check 3: Files Inside
Inside **Hiyuki** folder, you should have:
- ✓ `theme.xml`
- ✓ `theme.json`
- ✓ `colors.xml`
- ✓ `README.md`

### Check 4: Refresh
1. Close **Themes** app completely
2. Reopen **Themes** app
3. Pull down to refresh
4. Search for "Hiyuki"

### Check 5: Restart
1. Restart your phone
2. Open **Themes** app again
3. Theme should now appear

## 🔧 Troubleshooting

### Problem: Theme doesn't show in list

**Solution A:**
```
1. Close Themes app
2. Reopen Themes app
3. Pull down to refresh (⬇️)
4. Look for "Hiyuki"
```

**Solution B:**
```
1. Settings → Apps → Themes
2. Tap "Storage" → "Clear Cache"
3. Reopen Themes app
4. Refresh
```

**Solution C:**
```
1. Restart phone
2. Open Themes app
3. Refresh (pull down)
4. Apply theme
```

### Problem: Theme applies but colors look wrong

**Solution:**
1. Make sure Night Light is OFF
2. Check Display settings
3. Try clearing cache again
4. Reapply theme

### Problem: Can't find Themes app

**Try:**
- Settings → Personalization → Themes
- Settings → Display → Themes
- Settings → System → Themes
- Or search "Theme" in Settings

## 💡 Tips

### Backup Current Theme
Before applying new theme:
1. Open Themes app
2. Find your current theme
3. Tap menu (⋮) → "Save as Custom"
4. You can restore it later

### Revert to Default
If you want to go back:
1. Open Themes app
2. Find "Default" or "System Default"
3. Tap Apply

### Combine with Other Customization
You can still:
- Use custom wallpapers
- Change fonts (if system supports)
- Adjust display settings
- Use custom icons (if system supports)
