# Game Turbo Theme

## Hiyuki Game Turbo UI (POCO HyperOS 3)

### Components:
- `game_turbo_config.json` - Configuration
- `interface/` - Game Turbo interface elements
- `icons/` - Performance monitoring icons
- `effects/` - Visual effects

### Features:
- Hiyuki-themed Game Turbo interface
- Red accent colors (#C41E3A) for performance indicators
- Custom performance graph styling
- FPS counter with theme integration
- Transparent overlay with high contrast

### Performance Indicators:
- **CPU Usage Display**: Real-time monitoring
- **RAM Usage Display**: Memory usage graph
- **Temperature Monitoring**: Thermal status
- **FPS Counter**: Game frame rate display
- **Network Speed**: Internet speed indicator

### UI Colors:
- **Interface**: Red (#C41E3A)
- **Background**: Black (#000000) with transparency
- **Text**: White (#FFFFFF)
- **Accent**: Light Red (#E8A8B8)

### Layout:
- **Position**: Top right corner
- **Size**: Compact
- **Transparency**: 0.9 (90% opaque)
- **Animation**: Smooth with 300ms duration

### Customization:
Edit `game_turbo_config.json` to adjust:
- Colors and styling
- Indicator visibility
- Animation speed
- Layout position
