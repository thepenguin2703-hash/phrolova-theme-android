# App Backgrounds Theme

## Application Background Themes

### Included:
- `app_config.json` - Configuration and gradients
- `app_bg.png` - Default app background
- `app_cards/` - Card-style backgrounds
- `gradients.json` - Gradient configurations

### Design Philosophy:
- Light background with subtle Hiyuki elements
- Red accent elements throughout
- Minimalist design to avoid clutter
- Consistent with lock screen and home screen
- Smooth transitions and shadows

### Apps Customized:
- System apps (Settings, Phone, Contacts)
- Control Center
- Notification drawer
- Settings interface
- App launcher
- Quick settings

### Available Gradients:

1. **hiyuki_main** (Default)
   - From: #FAFAF8 (Off-white)
   - To: #F5F5F5 (Light white)
   - Usage: Main app backgrounds

2. **hiyuki_accent** (Red accent)
   - From: #C41E3A (Primary red)
   - To: #8B0000 (Dark red)
   - Usage: Accent elements, buttons

3. **hiyuki_light** (Light accent)
   - From: #FFFFFF (White)
   - To: #E8A8B8 (Light red)
   - Usage: Highlight cards, overlays

### Card Styling:
- **Background**: White (#FFFFFF)
- **Shadow Color**: Light red (#E8A8B8) for depth
- **Border**: Light gray (#E0E0E0) for definition
