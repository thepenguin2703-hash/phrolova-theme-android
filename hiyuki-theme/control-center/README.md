# Control Center Theme

## Hiyuki Control Center Customization

### Included Files:
- `colors.json` - Color configuration
- `backgrounds/` - Control center background images
- `icons/` - Quick settings icons

### Theme Details:
- Primary Color: Red (#C41E3A) - Hiyuki's signature color
- Background: White/Light gradient
- Icon Style: Minimalist with red accents
- Icon Background: Soft white with subtle shadows

### Installation:
Place these files in your HyperOS 3 theme folder.
