# Settings UI Theme

## Hiyuki Settings Interface

### Customizations:
- `colors.json` - UI colors and styling
- `background.png` - Settings background (optional)
- `icons/` - Settings category icons
- `settings_config.json` - Layout configuration

### UI Elements:
- **Header**: Red background (#C41E3A) with white text
- **Background**: Light off-white (#FAFAF8)
- **Text**: Black primary text (#000000), gray secondary (#666666)
- **Toggle Switches**: Red when active, gray when inactive
- **Icons**: All in signature red color
- **Buttons**: Red primary buttons with white text

### Color Scheme:
| Element | Color | Hex Code |
|---------|-------|----------|
| Primary Text | Black | #000000 |
| Secondary Text | Gray | #666666 |
| Background | Off-white | #FAFAF8 |
| Header | Red | #C41E3A |
| Highlights | Red | #C41E3A |
| Dividers | Light Gray | #E0E0E0 |
| Toggle Active | Red | #C41E3A |
| Icons | Red | #C41E3A |

### Features:
- Consistent red accent throughout
- Clean, minimalist design
- Easy to read typography
- Smooth transitions between sections
