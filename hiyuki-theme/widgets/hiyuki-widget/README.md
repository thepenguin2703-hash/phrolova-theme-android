# Hiyuki Widget

## Custom Hiyuki Character Widget

### Features:
- Large Hiyuki character display
- Dynamic animation based on time and interaction
- Weather integration
- Date and time display
- Interactive tap effects
- Smooth idle animations

### Available Sizes:

1. **Small (2x2 grid)**
   - Compact display
   - Shows character portrait
   - Time and date in corners

2. **Wide (4x2 grid)**
   - Extended horizontal layout
   - Full character display
   - Time, date, and weather
   - Additional info panel

3. **Large (4x4 grid)**
   - Full detailed display
   - High-resolution character artwork
   - Complete information display
   - Weather forecast
   - Custom widgets integration

### Widget Configuration:
- **Background**: Light off-white (#F5F5F5)
- **Text**: Black (#000000)
- **Accent**: Red (#C41E3A)
- **Border**: Light red (#E8A8B8)

### Features:
- ✅ Character Display - Shows Hiyuki artwork
- ✅ Time Display - Digital clock
- ✅ Weather Integration - Real-time weather data
- ✅ Date Display - Current date
- ✅ Custom Animations - Theme-specific effects

### Animations:
- **Idle Animation**: "hiyuki_breathing" - Gentle breathing effect
- **Tap Animation**: "hiyuki_glow" - Red glow on tap
- **Duration**: 1000ms per animation cycle

### Widget Interactions:
- Tap to trigger glow effect
- Long press for customization
- Swipe for additional info

### Asset Files:
- `assets/hiyuki_portrait.png` - Main character image
- `assets/hiyuki_full.png` - Full body image
- `assets/frame.png` - Widget frame
- `animations/` - Animation frames
