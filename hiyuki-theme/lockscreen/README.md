# Lockscreen Theme

## Hiyuki Lockscreen Customization

### Components:
- `lock_config.json` - Lock screen configuration
- `wallpapers/` - Lockscreen wallpaper images
- `widgets/` - Lockscreen widgets (clock, weather, etc.)

### Features:
- Hiyuki character artwork as main wallpaper
- Custom clock widget with Hiyuki theme
- Fingerprint animation integration
- Lock icons customized with red theme
- Minimal notification style

### Color Palette:
- Red (#C41E3A)
- White (#F5F5F5)
- Black (#000000)

### Widget Positions:
- Clock: Top center
- Date: Middle center
- Notifications: Bottom
