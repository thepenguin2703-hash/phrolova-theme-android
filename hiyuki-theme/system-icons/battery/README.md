# Battery Indicator Theme

## Hiyuki Battery Customization

### Components:
- `battery_config.json` - Battery configuration
- `icons/` - Battery percentage icons (0-100%)
- `charging-effects/` - Animation frames for charging state

### Charging Animation:
- Smooth charging effect with Hiyuki-themed colors
- Red glow effect during charging (signature Hiyuki color)
- Particle effects aligned with theme
- 20 animation frames for smooth transition

### Battery Levels & Colors:
- **Critical (0-20%)**: Red (#FF0000) - Alert animation
- **Low (20-50%)**: Orange (#FFA500) - Warning animation
- **Medium (50-80%)**: Yellow (#FFFF00) - Normal animation
- **Full (80-100%)**: Green (#00AA00) - Full animation

### Charging Effect Details:
- Type: Glow effect
- Intensity: High
- Color: #C41E3A (Primary red)
- Supports both portrait and landscape
