# Homescreen Theme

## Hiyuki Homescreen Customization

### Components:
- `homescreen_config.json` - Home screen configuration
- `wallpapers/` - Home screen background images
- `widgets/` - Custom Hiyuki widgets
- `icons/` - App icons (optional)

### Available Widgets:
- Hiyuki Character Widget (displays Hiyuki artwork)
- Weather Widget (Hiyuki themed)
- Calendar Widget (with Hiyuki color scheme)
- Music Player Widget (custom styling)
- Clock Widget (minimalist)

### Design Notes:
- Minimalist layout with red accents
- Light background to highlight Hiyuki artwork
- Smooth animations and transitions
- Icon colors match the red/white theme

### Customization:
Edit `homescreen_config.json` to change:
- Widget styles
- Background colors
- Text colors
- Accent colors
